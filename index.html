Storm-0940 uses ARTEX agentic AI in ConnectWise supply-chain hack

  • 2,250+ tenants targeted
  • 2,900 attempts/min
  • 162 confirmed compromised

A China-state-aligned group used ARTEX, an open-source multi-agent AI penetration-testing framework, to automate scanning, password spraying and OAuth app abuse. After compromising ConnectWise Cloud Backup (formerly SkyKick) app identities, it tried to sign in to 2,250+ Microsoft 365 tenants; Huntress confirmed 162 compromised tenants in its view.

  • Keep ConnectWise app connections disabled Until ConnectWise publishes restoration steps
  • Don't delete the enterprise apps first Preserve the evidence
  • Search tenants by app ID 506e08f9-6e9a-4da4-942b-a099a03644ae, 24205314-2b89-4e07-a2a4-579e898a5640, 0de14c77-b9b0-4137-9360-34878a929827
  • Review service-principal sign-ins From at least 15 Oct, ideally 1 Oct
  • Look for new app credentials, role assignments, consent grants, inbox and forwarding rules
  • Block IPs 144.172.64.99, 144.172.64.60, 144.172.64.128
  • Apply least privilege to multi-tenant apps
Type
AI-DRIVEN
Who's affected
Orgs that ever authorized the ConnectWise Cloud Backup, ConnectWise MS Teams or ConnectWise MS Graph apps

Oct 2026

AI-assisted global hacking campaign using Claude Code, Codex, Grok and DeepSeek

Zscaler ThreatLabz found attackers chaining several AI coding agents (with ARTEX on DeepSeek) that split tasks, reviewed each other's work and kept context across accounts; prompts sought bulk personal and transaction data to sell. Palo Alto Unit 42 separately documented an actor using AI to plan intrusions, including exfiltrating a MongoDB database from an Indian public university.

  • Lock down internet-facing databases No public MongoDB; require authentication
  • Enforce MFA and rate limiting on logins
  • Monitor for machine-speed parallel logins from one IP
  • Rotate exposed keys
Type
AI-DRIVEN
Who's affected
Anyone with exposed databases or logins without MFA and rate limits

Malicious LiteLLM 1.107.0 on PyPI steals AI and cloud credentials

  • ~2 hours live
  • Safe: 1.106.2

For about two hours the AI gateway library shipped a release with a credential stealer and an hourly backdoor that runs on any Python start, even without importing litellm. It grabbed SSH keys, cloud creds, CI secrets, browser passwords, AI coding tool tokens and LLM provider API keys. It was released via stolen GitHub CLI OAuth tokens.

  • Pin litellm==1.106.2
  • If 1.107.0 was installed, delete cook.pth, cook.py and sitecustomize.py from site-packages Before running pip
  • Kill the background Python process, then rebuild the environment
  • Rotate every cloud role, proxy DB password, master key and provider API key
  • Check Docker pulls of the latest, main-latest and main-stable tags
Type
AI SUPPLY CHAIN
Who's affected
Anyone who installed LiteLLM 1.107.0 or pulled its affected Docker tags
Source
TSN Media

2026

Prompt injection against AI agents via MCP

Google and four other orgs acknowledged agent flaws where hidden instructions in content hijack AI agents. Because MCP servers store credentials for every tool, one injection can exfiltrate data. Salesforce Agentforce was hijacked through unauthenticated Web-to-Lead form text.

  • Treat all content an agent reads as untrusted
  • Give agents least-privilege, scoped credentials
  • Require human approval for sends, payments and deletions
  • Separate read tools from write tools
  • Log every tool call
Type
AI-DRIVEN
Who's affected
Teams running AI agents connected to tools through MCP, including Salesforce Agentforce
Source
Ars Technica

Deepfake voice fraud tricks Fideuram (Intesa Sanpaolo) into ~$100M+ in transfers

  • ~$60M recovered
  • ~$40M missing

Attackers sent a WhatsApp message impersonating the CEO, then used an AI-cloned voice of a law-firm partner to "confirm" urgent transfers.

  • Verify any payment request by calling back on a number you already have
  • Require two-person approval for large transfers
  • Agree a family or company code word
  • Never treat a voice or video call as proof of identity
Type
AI-DRIVEN
Who's affected
Finance teams and anyone who approves transfers by message or phone

Evergreen checklist

Nine habits that blunt most of the attacks on this page.

01

Turn on automatic updates

For OS, browser, apps and self-hosted servers. Check the CISA KEV catalog weekly.

02

Use phishing-resistant MFA

Passkeys or hardware keys, everywhere they're offered.

03

Use a password manager and unique passwords

Check your exposure at Have I Been Pwned.

04

Never paste commands from a "verify you're human" prompt

That's the ClickFix trick.

05

Pin and verify dependencies

Enable lockfiles and 2FA on package and GitHub accounts; rotate tokens after any supply-chain alert.

06

Give AI agents least privilege

Require human approval for sends, payments and deletes.

07

Verify money or credential requests out-of-band

Deepfake voices and video are now cheap.

08

Keep admin consoles off the public internet

VPN, firewall, backup, GitLab, Plex.

09

Keep offline or immutable backups

And test your restores.

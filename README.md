# Cyber & AI Attack Watch

A living tracker of cyberattacks and AI-driven attacks, each paired with researched, vendor-confirmed fixes, updated as new attacks land.

Maintained by **Yashwin** and **Hark**.

## What's inside
- AI-driven attacks (agentic AI intrusions, AI supply-chain compromises, prompt injection, deepfake fraud) with fix checklists
- Patch-now table of actively exploited flaws and their fixed versions
- Breach timeline and an evergreen protection checklist

## Adding a new attack
Open `index.html`, find the comment `ADD NEW ATTACKS HERE (newest first)`, copy an existing attack block and paste it directly under that comment. Every fix must link to a primary source (vendor advisory, CISA KEV, or the researcher's report). Update the "Last updated" date.

## Run locally
Open `index.html` in a browser. No build step.

## Disclaimer
Informational only. Always validate fixes against the vendor's current guidance before applying them.
